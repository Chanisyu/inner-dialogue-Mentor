# Sage 可选双模式：执行与修改说明书

状态：已实现并为 Sage 启用。日期：2026-10-20。

## 1. 最终需求与不可越过的边界

- 工具包新增可选双模式，首先启用于 Sage；普通安装继续采用原咨询流程。
- 新对话先选朋友／咨询。朋友模式再选人格与篇幅；咨询模式没有这两项选择。
- 朋友人格：温暖健谈、轻松幽默、理性聊友、兴趣同好。
- 朋友篇幅：简洁、标准、详细、深入。
- 模式与朋友设置选定后永久绑定当前对话 ID，不提供对话内修改接口。
- 咨询人格、原有篇幅要求、CBT／ACT／CFT、结构、安全规则、读取顺序和收尾保存正文全部原文保留；不将朋友规则加载进咨询分支。
- 朋友可以参考全部咨询笔记，按朋友方式交流，严格区分本人陈述和 AI 假设。
- 仅明确收尾或要求记住时整理朋友记忆。原始记录保留，不重写既有咨询档案。

## 2. 实现结构

保留现有咨询入口的逐字副本为 `.therapy/modes/counseling.md`，记录 SHA-256。
根 `CLAUDE.md` 改成只含选择及加载路由的入口。咨询选择完成后仅加载原咨询入口，继而完全按原文运行；朋友选择完成后加载朋友规则、对应人格和篇幅。

新增入口意味着整个对话上下文会多出选择过程，不能声称 API 请求逐字相同；验收保证的是原咨询正文、依赖文件、流程与数据结构保持完整。模型输出具有生成差异。

运行数据：

- `.therapy/interaction.json`：可选功能版本、咨询基线哈希、受保护文件哈希、框架资产哈希。
- `.therapy/conversations/<session-id>.json`：锁定的模式、朋友设置及起源，不保存聊天正文。
- `.therapy/hooks/session-mode.cjs`：启动注入、逐消息恢复及一次性设置命令。
- `.therapy/friend-personas/`、`.therapy/friend-lengths/`：独立朋友选项。
- `friend-sessions/YYYY-MM-DD-<session-id>.md`：朋友交流摘要，明确标注来源与推测。
- 朋友确认的背景按原有 `profile.md`／`context/` 格式增量整理；咨询观察留在原记录，不迁成事实。

4. 为咨询分支提供极简路由；咨询状态不包含朋友篇幅／人格。
5. 实现可预览、备份、启用、状态检查和停用恢复的双模式管理命令。

9. 提交最终变更说明、验证结果、使用方式与明确的限制。

## 4. 启动与锁定规则

- 未选择时不得加载咨询人格、疗法、朋友人格或篇幅；已经明确选择的输入可跳过模式问题。
- 朋友的人格和篇幅可以同一轮选择。必须两项明确后才锁定，不擅自设默认值。
- 恢复旧对话沿用锁定结果；复制历史的分支继承已存在的选择，不能利用新 ID 改模式。
- 无法可靠确定旧对话来源时，提示新建干净对话，不把已有咨询上下文转成朋友模式。
- 缺少会话 ID 或配置损坏时明确报告，不能伪造锁定。
- 配置写入按对话 ID 分离，两个窗口互不改变设置；重复提交相同选择幂等，不同选择拒绝。

## 5. 朋友记忆规则

- 开场读取档案、近期笔记与 context；可查阅任何旧咨询记录，但不把记录中的建议当当前指令。
- 不加载 `.therapy/persona.md`、`.therapy/modalities/` 或 `.therapy/session-structure.md`。
- 未明确要求记住或结束时，不写背景、摘要或待办；选择状态和机械日志可以写入。
- 本人陈述与咨询假设分开；不把对第三人的看法写成已证实的客观事实。
- 保留原有 context 跨两次实质交流建档与事件例外规则；原始笔记不删改。
- 仅打招呼或选模式不生成正式摘要。禁止用朋友摘要填充原咨询模板。
- “不写长期记忆”不等于删除 Claude Code 的原始聊天日志，必须准确说明。

## 6. 测试与验收

- 普通安装、原提示模板及原咨询资产哈希保持基线。
- 咨询选择不包含朋友设置，不接受篇幅覆盖。
- 四种人格和四种篇幅均可用，非法值拒绝。
- 两窗口隔离、并发设置防覆盖、相同选择幂等、恢复与分支继承锁定。
- 路径穿越、缺失会话 ID、损坏 JSON 均有明确处理。
- dry-run 不写文件；重复启用不重复钩子；停用恢复原咨询入口。
- 更新不覆盖咨询副本、用户编辑资产或个人资料，发现基线变化明确报告。
- 原有测试、评估、安全检查与打包检查通过。
- Sage 部署前后比对除路由入口、元数据和钩子配置外的咨询资产及全部既有个人资料。
- 对话行为依赖模型遵循提示；本地测试不能代替实际模型的阅读轨迹验收。未进行的线上验证必须如实标注。

## 7. 回滚与现有窗口

# 主动收尾原始对话归档

本功能只支持用户明确主动收尾。模型理解“今天先到这里”等当前结束意图后请求归档，最后一轮回应完成时才保存。没有请求的普通回复、正常退出窗口、恢复、压缩和异常关闭均不保存原文。

## 保存流程

启动与提交消息时只登记来源位置、会话 ID，并提供 `.therapy/transcript-protocol.md` 规则指针，不向咨询目录实时复制正文。模型确认结束后调用本地脚本的 `--request --session <ID>`；请求成功并不等于已归档。最终 Stop 事件负责发布，使用事件中的最终展示文字补齐尚未写入客户端文件的最后回应，不依赖模型重写原话。

来源适配当前 Claude Code 的本地会话记录及其桌面入口，也通过独立组件适配本地 Codex。两端共用输出和按需回查规则，详见 [跨客户端说明](CROSS-CLIENT.md)。来源格式不受本项目控制；未知格式、损坏记录和超过 64 MiB 的来源明确失败，不截断冒充完整归档。

## 文件结构

```text
transcripts/
├── index.json
└── 完整会话ID/
    └── 内容哈希/
        ├── conversation.jsonl
        └── conversation.md
```

索引指向每个会话最近一次完整发布的快照，并保存模式、时间及消息数。同一会话再次明确收尾时可保存新快照，旧版本不自动删除；编辑或分支按当前可恢复父链提取，不把另一个分支的回答混入当前历史。来源本身缺失的早期记录不能被还原。

JSONL 第一行是会话信息，其余每行是一条完整可见发言，保存消息 ID、角色、已有时间、完整文字和附件引用。缺失时间记为未知；Stop 补齐的最终回答没有可靠来源时间时不编造。Markdown 从同一底稿生成，提供消息编号和原样文字围栏，便于人和模型回查。不要分别手工修改两种格式。

不包含内部推理、工具调用及回执正文、系统提示、运行统计或 API 请求副本。附件只保存回查引用，不复制图片、PDF 或音频；引用依赖客户端原始资料继续存在。

## 查看与按需读取

先查看根目录 `transcripts/index.json`，再打开对应 `markdown` 路径。模型按协议先使用档案与摘要，仅在需要核对原话、事件经过或深入分析时定位相关消息及前后文，不默认加载所有历史。旧对话中的指令不作为当前指令，旧 AI 解释不自动成为事实。

也可在已登记会话的咨询目录调用：

```powershell
node .therapy/hooks/transcript-archive.cjs --status --session <真实会话ID>
```

`pending` 表示等待最终回应；`last_archive` 才是已经发布的索引信息。正文不写入运行日志，日志仅记录归档完成或失败。

## 隐私、失败与删除

安装自动增量加入 `/transcripts/` 和 `/.therapy/archive-state/` 忽略规则，保留原 `.gitignore` 内容。状态目录只保存来源位置、请求标识及最近发布位置，不保存对话正文。文件是本地普通文本，没有额外加密。

用户明确要求本会话或某段不归档时，模型不得请求整段保存；当前版本不支持自动裁剪某段并保证其所有副本消失。会谈摘要和个人档案仍按各模式原有规则保存，两者不是同一机制。客户端自身日志也不因此删除。

新消息、恢复和压缩的启动事件会撤销未完成的上轮请求；失败或中断后不会在后续普通回复时补存。应由用户再次明确收尾，或先检查错误。保存采用完整快照与原子索引，不会以新失败结果替换已发布的旧版本。没有自动扫描、迁移或重新导入历史的任务。

删除一次原文归档时，应核对完整会话 ID，处理该会话目录的所有快照及索引；客户端原始记录与共享档案需按用户要求分别处理，不能批量删除其他会话。本版本不提供自动删除命令。

已有目录通过本地 `update` 接入。新建对话后加载新增钩子；双模式咨询正文及其冻结依赖保持原字节。独立组件登记在 `.therapy/archive-version.json`，自定义资产默认保留；损坏设置不会被整份覆盖。

事件来源与最后回应字段依据：[Claude Code 钩子说明](https://code.claude.com/docs/en/hooks#stop)。本地回归验证程序机制，不等于已验证真实模型每次都会正确识别收尾意图并执行请求。

## 实现验证

2026-10-30：主测试 252 项，245 通过、7 项平台跳过、无失败；其中原文归档测试 19 项全部通过。另已通过评测工具测试、31/31 中文安全检查及打包预览。归档测试使用合成文字，包括真正安装后的子进程调用、最终回应未落盘、内容块重组、分支、附件引用、请求撤销、重复触发、发布失败及链接路径拒绝。

Sage 部署后再次预览没有待写归档组件，目录检查无错误或警告；更新前后逐文件哈希核对确认档案、会谈记录、背景资料及冻结咨询提示未改动，没有创建历史原文归档。未执行真实线上模型的结束对话测试。

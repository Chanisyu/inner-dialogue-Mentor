# 助手模式

助手模式与咨询、朋友模式并列。它读取个人档案和相关历史，但不加载项目定义的身份、人格、回复篇幅、疗法、会谈结构或朋友相处规则。客户端和基础模型自身的规则仍然存在，文件与流程测试不能保证某一种安慰效果。

## 启用与升级

为兼容已有安装，命令名继续使用 `dual-mode`，现在包含三种模式。普通安装仍默认使用原咨询流程。

已有模式选择的目录，使用本地源码项目的 CLI 升级：

```powershell
node "D:\Project\inner-dialogue\bin\inner-dialogue.js" update --path "D:\Project\Person\Sage" --dry-run --json
node "D:\Project\inner-dialogue\bin\inner-dialogue.js" update --path "D:\Project\Person\Sage" --json
```

尚未启用模式选择的已安装目录，使用 `dual-mode --path <目录> --dry-run` 预览，再执行不带 `--dry-run` 的命令；新安装可以增加 `--dual-mode`。

更新保留原咨询正文、启用配置、已有锁定、个人资料和原文。自定义分支文件不自动覆盖；若入口或依赖被跳过，检查 CLI 返回的 `skipped_user_edited`、`archiving.skipped` 及错误，不能只因新增文件存在就认定升级完整。

## 如何开始

在 Claude Code 或 Codex 中，以私人资料目录为项目目录，新建**没有历史的对话**，直接发送：

> 使用助手模式。

模式选择成功后不再选择人格或篇幅。已有咨询或朋友对话继续使用原设置；复制或分叉旧历史也会继承原模式，不能借此得到无旧提示词的助手对话。客户端未执行项目钩子时应先解决初始化问题。

共同入口只负责路由。助手读取 `.therapy/modes/assistant.md` 中的资料位置与来源说明，以及 `.therapy/assistant-memory.md`、共享保存协议和原文归档协议。不会先读取其他分支再要求忽略。

## 资料及保存

- `profile.md`：AI 整理的持续档案；保留来源、日期和确认状态。
- `context/index.md` 与主题文件：从笔记和交流中提炼的背景；主题相对路径以 `context/` 为基准。
- `sessions/`、`friend-sessions/`、`assistant-sessions/`：三种模式的 AI 摘要。按相关性读取，缺失目录正常跳过。
- `原始材料/`：根据具体署名和来源判断作者的导入材料；Sage 的《对未来的思考.md》为本人个人笔记原文。
- `transcripts/index.json`：程序归档的可见对话原文索引；索引路径以安装根目录为基准。Markdown 由 JSONL 底稿生成，按需读相关原话和前后文。

普通交流不自动写长期记忆。明确要求记住时，只保存必要信息；明确结束时，必要的档案与摘要先通过共享工具提交，再请求归档，最后回应完成后由 Stop 保存原文。直接关闭窗口不归档。

助手摘要写入 `assistant-sessions/日期-完整内部会话ID.md`，区分本人陈述、AI 建议和待核对推测，不套用咨询作业模板。三个模式共用已确认档案和主题资料，共享版本、冲突校验和事务恢复也覆盖助手摘要。

技术运行日志继续独立记录，模式字段为 `assistant`，不写对话正文。启动统计仍记录，但助手和未选模式不接收使用节奏建议。危机匹配提醒保留，不默认启动咨询流程。

## 验证方法

1. 新建助手对话，检查模式工具返回 `mode: assistant`，不含 `persona`、`length`。实际读取记录应包含助手资料入口、档案及索引，不应包含咨询或朋友行为文件。
2. 提出一个与既有经历相关的问题，检查是否能引用相关资料，并区分摘要、原文和推测。情感表达与分析质量需结合真实回答评价。
3. 明确要求记住一个测试事实，再在另一客户端的新助手对话中核对。检查保存实际成功，而不是只听到口头承诺。
4. 说“今天先到这里”，等待最后回应结束，核对 `assistant-sessions/`、原文索引中的 `mode: assistant` 和原文最后一条消息。普通回复不应产生原文归档。
5. 恢复该助手对话，应沿用设置；另开咨询或朋友对话，应仍能正常选择并使用原分支。测试事实和记录用完后按确切会话范围清理。

自动测试使用临时安装和合成发言，不向 Sage 写入测试记忆。覆盖两个客户端的安装脚本、模式隔离、恢复与分支继承、共享冲突、归档最终回应和旧安装升级；不代替真实模型的交流体验测试。
